# Laboratório de Simulação Biológica

<BlockImage id = "biological_simulation_laboratory" scale = "8"/>

* Só podem ser instaladas escotilhas de laser de nível <Color color="#FFFF00">**UXV**</Color> ou superior

> A máquina tem uma contagem de paralelismo inicial de 64, e pode receber bônus adicionais ao colocar os enxames de nano correspondentes na máquina principal \
> Ao colocar <Color color="#CBCFD7">**Enxame de Nano de Rênio**</Color>, a **contagem de paralelismo** é 2048, o bônus do **multiplicador de tempo** é 0.9, o bônus do **multiplicador de energia** é 0.9 \
> Ao colocar <Color color="#FF78C9">**Enxame de Nano de Adamantita**</Color>, a **contagem de paralelismo** é 16384, o bônus do **multiplicador de tempo** é 0.6, o bônus do **multiplicador de energia** é 0.8 \
> Ao colocar <Color color="#FF77FF">**Enxame de Nano do Infinito**</Color>, a **contagem de paralelismo** é 262144, o bônus do **multiplicador de tempo** é 0.4, o bônus do **multiplicador de energia** é 0.6 \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, a **contagem de paralelismo** é 4194304, o bônus do **multiplicador de tempo** é 0.1, o bônus do **multiplicador de energia** é 0.25 \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, além de obter os bônus acima, também permite que a máquina trabalhe em modo de processamento de múltiplas receitas \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, também desbloqueia receitas que exigem a **Espada do Infinito** como entrada \
> Você pode escolher se deseja executar no modo de processamento de múltiplas receitas na interface GUI da máquina principal \
> O modo de múltiplas receitas da máquina só pode selecionar o **Modo de Divisão Igualitária**, não o **Modo Extremo**
