# Laboratório de Simulação Biológica

<BlockImage id = "biological_simulation_laboratory" scale = "8"/>

* Só podem ser instaladas laser hatches de nível <Color color="#FFFF00">**UXV**</Color> ou superior

> A máquina tem uma contagem de paralelismo inicial de 64, e pode receber bônus adicionais ao colocar os nano enxames correspondentes na máquina principal \
> Ao colocar <Color color="#CBCFD7">**Nano Enxame de Rênio**</Color>, a **contagem de paralelismo** é 2048, o bônus do **multiplicador de tempo** é 0.9, o bônus do **multiplicador de energia** é 0.9 \
> Ao colocar <Color color="#FF78C9">**Nano Enxame de Adamantita**</Color>, a **contagem de paralelismo** é 16384, o bônus do **multiplicador de tempo** é 0.6, o bônus do **multiplicador de energia** é 0.8 \
> Ao colocar <Color color="#FF77FF">**Nano Enxame do Infinito**</Color>, a **contagem de paralelismo** é 262144, o bônus do **multiplicador de tempo** é 0.4, o bônus do **multiplicador de energia** é 0.6 \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, a **contagem de paralelismo** é 4194304, o bônus do **multiplicador de tempo** é 0.1, o bônus do **multiplicador de energia** é 0.25 \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, você não só obtém os bônus acima, como também permite que a máquina trabalhe em modo de processamento multi-receita \
> Ao colocar <Color color="#FF00FF">**Certificado Nano**</Color>, também desbloqueia receitas que exigem a **Espada do Infinito** como entrada \
> Você pode escolher se deseja executar no modo de processamento multi-receita na interface GUI da máquina principal \
> O modo multi-receita da máquina só pode selecionar o **Modo de Divisão Igualitária**, não o **Modo Extremo**
