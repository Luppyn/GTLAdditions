# Tipos de Receita Múltiplos

* Quando uma máquina permite processar tipos de receita múltiplos, todas as receitas dentro de cada tipo de receita múltiplo podem ser processadas sem modificar o tipo de receita
* Por exemplo: Se um tipo de receita múltiplo inclui Pirolisador e Craqueador, após selecionar esse tipo de receita múltiplo, todas as receitas de ambos os tipos de receita podem ser processadas sem alterar o tipo de receita da máquina
* ~~(Não é possível garantir que todos os tipos de receita múltiplos não terão conflitos de receita)~~
* ~~"receita paralela entre modos + tipos de receita múltiplos = tipos de receita paralelos entre modos"~~
