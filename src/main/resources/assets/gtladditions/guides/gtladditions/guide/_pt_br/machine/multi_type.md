# Múltiplos Tipos de Receita

* Quando uma máquina permite processar múltiplos tipos de receita, todas as receitas dentro de cada tipo de receita múltipla podem ser processadas sem modificar o tipo de receita
* Por exemplo: Se um tipo de receita múltipla inclui Pirolisador e Craqueador, após selecionar esse tipo de receita múltipla, todas as receitas de ambos os tipos de receita podem ser processadas sem alterar o tipo de receita da máquina
* ~~(Não é possível garantir que todos os tipos de receita múltipla não terão conflitos de receita)~~
* ~~"receita paralela entre modos + tipos de receita múltipla = tipos de receita paralelos entre modos"~~
