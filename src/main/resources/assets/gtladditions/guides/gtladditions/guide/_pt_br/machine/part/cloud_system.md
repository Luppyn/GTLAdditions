* Você pode fabricá-lo no estágio <Color color="#55FF55">**UEV**</Color>
* A Hatch Transmissora de Computação em Nuvem equivale à <ItemLink id="gtmthings:wireless_computation_transmitter_hatch" />, enquanto a Hatch Receptora de Computação equivale à <ItemLink id="gtmthings:wireless_computation_receiver_hatch" />; o Monitor de Computação em Nuvem é responsável por monitorar o status de entrada/saída de computação do sistema de computação em nuvem
* Apenas estruturas multibloco com capacidade de ponte podem fornecer computação ao sistema de computação em nuvem; assim que o monitor de computação em nuvem destacar as coordenadas, se a máquina estiver na mesma dimensão que o jogador, a GUI será fechada e a visão do jogador será direcionada para a máquina; se estiver em uma dimensão diferente, o chat exibirá as coordenadas para as quais o jogador pode se teletransportar
* <ItemLink id="gtceu:network_switch" /> *não pode posicionar* a Hatch Transmissora/Receptora de Computação em Nuvem
* A Hatch de Dados de Pesquisa em Nuvem equivale à <ItemLink id="gtceu:wireless_data_receiver_hatch" />
* A Máquina de Dados de Pesquisa em Nuvem é responsável por armazenar módulos de dados, esferas de dados e memória flash no sistema de dados de pesquisa em nuvem; cada módulo de dados, esfera de dados ou unidade de memória flash aumenta o consumo de energia em 393.216 EU/t. Quando colocada dentro da Hatch de Acesso a Dados do Criativo, ela fornece todos os dados de pesquisa para todas as Hatches de Dados e o consumo de energia fica travado em 393.216 EU/t (a Hatch de Acesso a Dados do Criativo *não* será dropada quando a máquina for quebrada)
* Assim que o armazenamento em flash for vinculado, o sistema tentará automaticamente enviar os dados de pesquisa para a Máquina de Dados de Pesquisa em Nuvem disponível após a conclusão da pesquisa na <ItemLink id="gtceu:research_station" />; a detecção de ar dentro da estrutura da estação de pesquisa também foi descontinuada
* Todos os Sistemas de Computação em Nuvem/Dados de Pesquisa são capazes de funcionar *entre dimensões*
