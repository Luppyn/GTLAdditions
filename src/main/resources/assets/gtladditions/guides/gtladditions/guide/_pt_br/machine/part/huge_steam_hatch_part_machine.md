# Huge Steam Input Hatch

<BlockImage id="huge_steam_input_hatch" scale="8" />

* Você pode fabricá-lo no estágio <Color color="#AA00AA">**EV**</Color> ~~(o fim do EV também é o EV)~~
* O **Huge Steam Input Hatch** só pode ser instalado em estruturas multibloco a vapor, substituindo **Steam Input Hatches** ou **Large Steam Input Hatches**
* Ele pode elevar o nível de voltagem das receitas de processamento de estruturas multibloco a vapor para o nível <Color color="#FFAA00">**HV**</Color> (**Você pode instalá-lo em um Large Steam Macerator para obter subprodutos**)
* Ele pode reduzir o tempo de todas as receitas de processamento para 1t. A taxa de conversão de Steam para EU é 125 mB/t = 1 EU/t (**Por favor, preste atenção às suas reservas de steam!!!**)
