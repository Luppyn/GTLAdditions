# Escotilha de Barramento de Transmutação

<BlockImage id="gtladditions:me_block_conservation" scale="4" />

* Você pode fabricá-la no estágio <Color color="#00AA00">**UIV**</Color>
* Requer a inserção de uma **Célula de Armazenamento de Itens AE**. Todos os itens transmutados de saída são primeiro inseridos na célula e depois retornados à rede AE (não pode ser colocada em uma **Célula Portátil**)
* Segure <ItemLink id="gtceu:creative_data_access_hatch" /> e clique com o botão direito no **Barramento de Transmutação** para usá-lo na **Porta da Criação** e no **Agregador Criativo** (irá **consumir** uma Escotilha de Acesso de Dados Criativa)
* Outros métodos de uso são semelhantes ao **Barramento de Entrada ME**. Marque os itens de entrada e as quantidades para extrair automaticamente os itens correspondentes da rede AE
