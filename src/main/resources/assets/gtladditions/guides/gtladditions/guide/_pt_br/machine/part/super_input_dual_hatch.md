# Super Input Dual Hatch

<BlockImage id="super_input_dual_hatch" scale="8" />

* Você precisa alcançar o nível <Color color="#00AA00">**UIV**</Color> para fabricá-lo
* O Super Input Dual Hatch possui uma grande quantidade de slots de entrada, capaz de armazenar mais itens e fluidos do que o Huge Dual Input Hatch
* Possui 37 slots de itens, cada slot pode armazenar 2.147.483.647 (2,14G) itens
* Possui 24 slots de fluidos, cada slot pode armazenar 2.251.799.813.685.247mb (2,2TB) de fluido
* No entanto, ele tem uma desvantagem fatal: cada vez que devolve itens ou fluidos, só pode devolver no máximo 2,14G de itens ou 2,14MB de fluido, o que significa que se você inserir muito fluido no hatch, precisará clicar em devolver várias vezes para recuperar todos os itens e fluidos
