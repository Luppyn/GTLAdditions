# Sobre as modificações do Portal da Criação e do Agregador Criativo

<Row>
    <BlockImage id = "gtceu:door_of_create" scale = "4" />

    <BlockImage id = "gtceu:create_aggregation" scale = "4" />
</Row>

* Pode ser convertido instalando <ItemLink id="gtladditions:me_block_conservation" />
* Selecione o Circuito 24 no input bus para executar a conversão
* Apenas o **Cartão de Conversação Supremo** pode ser colocado na Máquina, que fornece bônus de paralelismo. A Máquina não funcionará sem ele
* Portal da Criação: 65536 paralelos; Agregador Criativo: 8192 paralelos
* Segure <ItemLink id="gtceu:creative_data_access_hatch" /> e clique com o botão direito no **Barramento de Transmutação** para instalar e permitir o funcionamento normal
* Outros métodos de uso do **Barramento de Transmutação** são semelhantes ao <ItemLink id="gtladditions:atomic_transmutation_core" />
* Selecione o circuito 1 no input bus para o modo vanilla
