# Sobre a Receita do Processador de Minério Integrado

Receita do <ItemLink id="gtceu:integrated_ore_processor" />

* ### Receita Nº1
> Receita com Circuito 24, entrada de <ItemLink id="gtceu:jasper_ore" />, pode obter diretamente <ItemLink id="gtceu:raw_tengam_dust" /> \
> Simplifica enormemente a obtenção de pó de tengam bruto \
> **Mas**: Esta receita só pode ser executada no <ItemLink id="gtceu:advanced_integrated_ore_processor" />!!!

* ### Receita Nº2
> Receitas com Circuito 8 e Circuito 9, entrada de <ItemLink id="gtceu:cooperite_ore" />, <ItemLink id="gtceu:chalcocite_ore" />, <ItemLink id="gtceu:bornite_ore" />, <ItemLink id="gtceu:tetrahedrite_ore" />  \
> Pode obter diretamente os minérios purificados correspondentes (produtos obtidos através do macerador e da lavadora de minério) \
> Simplifica ligeiramente a linha de processamento de platina \
> ~~Minérios brutos também podem ser usados para obter os produtos correspondentes~~ \
> ~~(A calcocita não possui receita com Circuito 9)~~
