# GTLAdditions 机器配置

大多数 GTLAdditions 机器的默认线程数为 128（在适用的情况下；作为参考，原版跨配方并行机器使用 64 线程）。

## **均分模式**

> 在均分模式下，机器将处理所有可处理的配方，并行配方会尽可能均匀分配 \
> 如果均分后的总配方时间超过 1,000 秒，则并行运行的配方数量将不会均匀分配；而是只运行一个可处理的配方 \
> 在此模式下，总并行数为：线程数 × 机器并行数
> 此模式不支持批量处理

## **极限模式**

> 在极限模式下，机器将集中处理一部分配方，具有无损超频和 1toc（无损超频和 1toc 的概念请参考任务书）\
> 在此模式下，可配置维护的加成将不会生效 \
> 在此模式下，线程数即为可处理配方的最大数量 \
> 此模式会自动启用批量处理且无法禁用 \
> 除非另有说明或由特定机制提供，非跨配方并行机器的 GTLAdditions 机器的运行也遵循与极限模式相同的机制

* 你可以在模组配置中选择默认模式。初始默认模式为 **均分模式**。

#### **配方的限制时长配置**

> 可以在部分 GTLAdditions 机器 GUI 的左下角打开该按钮以调整初始默认值。 \
> 初始默认值为 1 秒。范围为 5 tick（最小）到 10 秒（最大）。 \
> 默认值也可以在模组配置文件中修改。
