# 奥术星图

<BlockImage id = "arcanic_astrograph" scale = "8"/>

* 它可以与当前维度内所有的**万眼之谐**和**奥术星图**产生共鸣，从而获得并行数加成
* 最大并行数为 924 * ln(x)，其中 x = a + 15b
* 此处，a 代表当前运行的**万眼之谐**数量，b 代表当前运行的**奥术星图**数量
* 只有量子色动力学炸弹和宇宙元素的需求量会随并行数变化。耗电量和氢氦消耗量与**万眼之谐**一致
