# 生物模拟实验室

<BlockImage id = "biological_simulation_laboratory" scale = "8"/>

* 只能安装 <Color color="#FFFF00">**UXV**</Color> 及以上等级的激光仓

> 机器初始并行数为 64，可通过在主机器中放置对应的纳米蜂群获得额外加成 \
> 放置 <Color color="#CBCFD7">**铼纳米蜂群**</Color> 时，**并行数** 为 2048，**时间倍率** 加成为 0.9，**能量倍率** 加成为 0.9 \
> 放置 <Color color="#FF78C9">**精金纳米蜂群**</Color> 时，**并行数** 为 16384，**时间倍率** 加成为 0.6，**能量倍率** 加成为 0.8 \
> 放置 <Color color="#FF77FF">**无尽纳米蜂群**</Color> 时，**并行数** 为 262144，**时间倍率** 加成为 0.4，**能量倍率** 加成为 0.6 \
> 放置 <Color color="#FF00FF">**纳米证书**</Color> 时，**并行数** 为 4194304，**时间倍率** 加成为 0.1，**能量倍率** 加成为 0.25 \
> 放置 <Color color="#FF00FF">**纳米证书**</Color> 时，不仅能获得上述加成，还能使机器以多配方处理模式工作 \
> 放置 <Color color="#FF00FF">**纳米证书**</Color> 时，还会解锁需要 **无尽之剑** 作为输入的配方 \
> 你可以在主机器 GUI 界面中选择是否以多配方处理模式运行 \
> 机器的多配方模式只能选择 **均分模式**，不能选择 **极限模式**
