# 伏羲八卦天锻炉

<BlockImage id = "gtladditions:fuxi_bagua_heaven_forging_furnace" scale = "8"/>

* 拥有四种高效机器模式
* **分子解构**：将以往无法提取的粉末直接转化为流体，跳过电力高炉和提取机
* **恒星点火**：将流体直接转化为等离子体，跳过复杂的中间处理步骤
* **混沌炼金**：将合金炉和真空冷冻机整合为一步反应
* **终极物质锻造**：更高的并行处理，实际并行设置为并行仓上限的16倍
