# 巨型蒸汽输入仓

<BlockImage id="huge_steam_input_hatch" scale="8" />

* 你可以在 <Color color="#AA00AA">**EV**</Color> 阶段制作它 ~~（EV 的尽头还是 EV）~~
* **巨型蒸汽输入仓** 只能安装在多方块蒸汽结构上，用于替换 **蒸汽输入仓** 或 **大型蒸汽输入仓**
* 它可以将多方块蒸汽结构的处理配方电压等级提升至 <Color color="#FFAA00">**HV**</Color> 级别（**你可以把它装在大型蒸汽研磨机上以获取副产物**）
* 它可以将所有处理配方的时间缩短至 1t，蒸汽到 EU 的转换率为 125 mB/t = 1 EU/t（**请注意你的蒸汽储量！！！**）
~~与大型蒸汽输入仓一样，不要将其用于跨维度蒸汽烤箱~~
