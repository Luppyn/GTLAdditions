# 光谱分析仓

~~别名 OP 仓~~

<BlockImage id="spectral_analysis_hatch" scale="8" />

* 必须在 <Color color="#00AAAA">**UV**</Color> 电压等级下合成
* 光谱分析仓只能安装在集成矿石处理或进阶集成矿石处理上。它是一个额外的部件仓，且结构中只能安装一个
* 打开仓的 GUI 会显示三个频道，每个频道有三个指示灯
* 每个频段的频道编号随机生成 ~~（但遵循一定规律）~~
* 每个频道后点亮的指示灯数量代表对应的激活等级，<Color color="#00FF00">绿色表示激活状态</Color>，<Color color="#FF0000">红色表示未激活状态</Color>
* 激活等级 1（数值范围 **±80**），激活等级 2（数值范围 **±35**），激活等级 3（数值范围 **±5**）
* 你可以通过修改数值或拖动文本框下方的滑块来调整频道

* 频道 1：线程加成，直接应用于多配方处理线程
> **集成矿石处理**：等级 0（默认加成）：4 线程，等级 1：6，等级 2：8，等级 3：10
>
> **进阶集成矿石处理**：等级 0（默认加成）：72 线程，等级 1：96，等级 2：128，等级 3：144
* 频道 2：概率加成，所有概率产出电压提升概率 **直接乘以** 频道等级加一
> 例如：在等级 2 时，产出物品 A 的基础产出概率为 30%，基础电压加成概率为 5%，经过该频段加成后基础电压加成概率变为 (5 * (2 + 1)) = 15%
* 频道 3：独立加成，集成矿石处理与进阶集成矿石处理获得不同加成，安装在不同机器结构上时获得不同加成
> 安装在 **集成矿石处理** 上时，获得配方时间倍率加成（**直接相乘**）
>
> 安装在 **进阶集成矿石处理** 上时，获得流体消耗倍率加成（**直接相乘**）
>
> 加成倍率：等级 0（默认加成）：0.8，等级 1：0.65，等级 2：0.5，等级 3：0.4

* 此外，当输入频道与实际频道匹配（即零误差）时，称为完美调谐
* 当三个频道全部完美调谐时，机器超频从有损超频变为无损超频，并可使用极限处理模式进行更高效的配方处理，大幅提升机器处理效率
