# 超级输入双仓

<BlockImage id="super_input_dual_hatch" scale="8" />

* 你需要达到 <Color color="#00AA00">**UIV**</Color> 等级才能制作它
* 超级输入双仓拥有大量输入槽位，能够容纳比巨型双输入仓更多的物品和流体
* 拥有 37 个物品槽，每个槽位可容纳 2,147,483,647（2.14G）个物品
* 拥有 24 个流体槽，每个槽位可容纳 2,251,799,813,685,247mb（2.2TB）的流体
* 然而，它有一个致命缺点：每次返还物品或流体时，最多只能返还 2.14G 个物品或 2.14MB 的流体，这意味着如果你在仓中输入了过多流体，你需要多次点击返还才能取回所有物品和流体
